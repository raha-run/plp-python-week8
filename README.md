# Raha's Personal Mini-Toolkit

## Project Description

Raha's Personal Mini-Toolkit is a simple Python program that provides three useful tools through a menu. It includes a Simple Calculator, a To-Do List, and an Even Number Checker. The program uses loops, lists, conditionals, and f-strings to make the tools interactive and user-friendly.

## Tools Included

1. **Simple Calculator:** Performs basic mathematical calculations.
2. **To-Do List:** Allows users to manage tasks.
3. **Even Number Checker:** Checks whether a number is even or odd.

## How to Run the Program

1. Install Python on your computer.
2. Open the project folder in VS Code.
3. Open the terminal.
4. Run the command:

   `python toolkit.py`

5. Choose a number from the menu and follow the instructions.

## Python Concepts Used

- Variables and user input
- Loops
- If, elif, and else conditionals
- Lists
- F-strings
- Comments

## Reflection

The hardest part of this project was connecting all three tools to the menu loop. The bug that took the longest to fix was making sure the menu returned after a tool finished and stopped when the Quit option was selected. I also learned how to handle invalid menu choices without crashing the program. Building the calculator helped me practise basic calculations and user input. The To-Do List helped me understand how lists can change while a program runs. The Even Number Checker gave me more practice using conditionals. If I had one more week, I would add a number-guessing game and improve the menu design.
