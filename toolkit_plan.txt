Raha's Personal Mini-Toolkit Plan

1. Tools

Simple Calculator:
The calculator adds two numbers and displays the result.

To-Do List:
The To-Do List lets the user add tasks to a list that changes while the program runs.

Even Number Checker:
The Even Number Checker checks a number and tells the user whether it is even or odd.
